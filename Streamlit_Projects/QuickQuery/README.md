# 🚀 QuickQuery

> AI-Powered Natural Language SQL Assistant for MySQL Databases

QuickQuery is an AI-driven database analytics application that enables users to interact with MySQL databases using plain English.

Instead of writing SQL queries manually, users can ask questions in natural language, and QuickQuery automatically:

- Understands the user's intent
- Analyzes database schema
- Generates optimized SQL queries
- Executes queries securely
- Returns tabular results
- Provides insights from the returned data

Built using Streamlit, MySQL, Groq LLM, and modern AI engineering practices.

# 🎯 Problem Statement

Business users often struggle with SQL.

They may know what information they need but lack the technical expertise to write SQL queries.

Example:

❌ Traditional Approach

```sql
SELECT department,
       AVG(salary)
FROM employees
GROUP BY department;
```

Requires SQL knowledge.

---

✅ QuickQuery Approach

User asks:

> "What is the average salary by department?"

QuickQuery automatically:

1. Understands the request
2. Generates SQL
3. Executes query
4. Returns results

# 🔄 End-to-End Pipeline

## Step 1: Database Connection

User provides:

- Host
- Port
- Username
- Password
- Database Name

Application establishes MySQL connection.

---

## Step 2: Schema Discovery

QuickQuery extracts:

- Tables
- Columns
- Data Types
- Relationships

Example:

```text
customers
├── customer_id
├── first_name
├── email

orders
├── order_id
├── customer_id
├── total_amount
```

---

## Step 3: Prompt Engineering

Database schema is injected into the prompt.

Example:

```text
Database Schema:
customers(customer_id, first_name, email)

orders(order_id, customer_id, total_amount)

Question:
Show total revenue generated by each customer.
```

---

## Step 4: SQL Generation

Groq LLM generates SQL:

```sql
SELECT
    c.first_name,
    SUM(o.total_amount)
FROM customers c
JOIN orders o
ON c.customer_id = o.customer_id
GROUP BY c.first_name;
```

---

## Step 5: Query Validation

Before execution:

- Syntax checks
- Query sanitization
- SQL injection protection
- Read-only enforcement (optional)

---

## Step 6: Execution

Generated SQL is executed against MySQL.

---

## Step 7: Result Processing

Results converted into:

```python
pandas.DataFrame
```

---

## Step 8: Visualization

Displayed using Streamlit:

- Tables
- Metrics
- Charts
- Downloadable CSV
